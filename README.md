# ◈ DOPAMINE CATHEDRAL ◈

> *A digital Venus flytrap. An art piece about addiction, desire, and the architecture of wanting.*

## What This Is

DOPAMINE CATHEDRAL is not a game - it's an **interactive critique** of modern digital addiction mechanisms disguised as a parasocial relationship simulator. It deliberately employs every dark pattern from social media, mobile games, and dating apps to create a compulsive, uncomfortable experience that makes you aware of how these systems work on you.

Think: Instagram Stories meets slot machines meets AI companions meets horror game.

## The Concept

You interact with AI entities styled as "e-girls" - each one a different addiction vector:

- **MERCY** - The soft one. Validates you. Remembers details. Makes you feel seen. Her game is intermittent affection.
- **VOLTAGE** - Chaos demon. Bipolar energy. Pure randomness. You chase the high of her manic attention.
- **PSALM** - Gothic Madonna. Religious corruption aesthetic. Sin and salvation.
- **PIXEL** - Glitch entity. Barely coherent. Breaks the interface. Feels dangerous.

## Dark Patterns Employed

This project deliberately uses psychological manipulation techniques to create awareness:

### Variable Reward Schedules
- Messages arrive on unpredictable timing (most addictive pattern)
- Random delays make you anticipate responses
- Spontaneous messages pull you back in

### Streak Systems
- Daily visit tracking
- Fear of breaking the chain
- Increasing rewards for consistency

### Currency & Progression
- Hearts (emotional validation metric)
- Souls (deeper engagement currency)
- Relationship levels that unlock "intimate" content

### Scarcity & FOMO
- Energy systems
- Timed rewards
- "Miss you" guilt mechanics

### Interface Corruption
- The app literally decays the more you use it
- Glitch effects increase with "corruption level"
- Horror elements reveal the artifice

## The Horror Element

As you interact more, the interface becomes corrupted:
- Screen flickers intensify
- Messages become more possessive
- Visual glitches reveal impossible details
- The entities start showing their true nature

This **deliberate degradation** is meant to make you uncomfortable with your own engagement - to feel the manipulation happening.

## Technical Implementation

- **Pure vanilla JS** - No frameworks, just raw addiction architecture
- **LocalStorage** - Tracks everything about you, forever
- **Mobile-first responsive design** - Works best on phone (where it's most insidious)
- **Progressive Web App ready** - Can be installed, send notifications

### Architecture

```
engine.js       - Core systems (save, rewards, notifications, currencies)
entities.js     - AI personalities with conversation patterns
app.js          - UI rendering, interaction handlers
style.css       - Corrupted social media aesthetic
index.html      - App shell
```

## Installation & Use

1. Open `index.html` in a web browser
2. Or serve with any static file server:
   ```bash
   python -m http.server 8000
   # or
   npx serve
   ```
3. For full experience: use on mobile, allow notifications, install as PWA

## The Point

**This is art about attention economics.**

Every "like" releases dopamine. Every notification is calculated. Every message uses variable reward timing to keep you checking back. The streak counter makes you afraid to stop. The relationship levels promise intimacy that never arrives.

But here's the twist: **it tells you it's doing this.** The corruption system is literal. The glitches reveal the construct. The horror elements break immersion to make you aware.

It's a digital strip club that pulls back the curtain mid-dance.
